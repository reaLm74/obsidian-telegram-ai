# 🗺️ Roadmap: Obsidian Telegram AI — Апрель 2026 – Март 2027

## Общая стратегия

Плагин находится на стадии рабочего MVP с мощным фундаментом.
Год разбит на 4 квартала, каждый с чёткой темой:

| Квартал | Тема | Месяцы |
|---------|------|--------|
| **Q1** | Фундамент: AI-провайдеры, тесты, архитектура | Апрель – Июнь |
| **Q2** | Функциональность: контент, sync, UX | Июль – Сентябрь |
| **Q3** | Production: CI/CD, безопасность, производительность | Октябрь – Декабрь |
| **Q4** | Масштаб: комьюнити, экосистема, рост | Январь – Март 2027 |

### 0.2 Загрузчик контента (Web Scraper)

- [x] Реализовать защиту от переполнения токенов (обрезка слишком больших страниц по длине символов).

### 0.3 Интеграция с обработчиком сообщений и AI
- [x] Изменить поведение в `handleMessageText` (файл `handlers.ts`): не пропускать ИИ-обработку при `isOnlyUrl === true`, если включен тумблер `aiProcessLinks`.

**Результат:** Плагин научился переходить по отправленным в Telegram URL-адресам, читать сайты через `r.jina.ai` и делать по ним структурированные выжимки. При этом оригинальные ссылки автоматически сохраняются в конце заметки. Данный функционал включается в настройках (`PromptsModal`).

## ⚫ Фаза 8: Ноябрь — Производительность

### 8.1 Оптимизация загрузки
- [ ] Lazy-loading AI-модулей (не грузить Claude/Gemini код если выбран OpenAI)
- [ ] Отложенная инициализация CategoryManager (только если включена категоризация)
- [ ] Code splitting: основной bundle < 500KB
- [ ] Tree-shaking неиспользуемых зависимостей

### 8.2 Оптимизация runtime
- [ ] Worker thread для тяжёлых операций (PDF-парсинг, base64 больших изображений)
- [ ] Интеллектуальный debounce для `saveSettings()` (сейчас вызывается на каждое изменение поля в модалке)
- [ ] Пул соединений для параллельных AI-запросов (лимит 3-5 одновременных)
- [ ] Стриминг ответов AI (SSE) вместо ожидания полного ответа

### 8.3 Метрики
- [ ] Замер времени обработки каждого сообщения (p50, p95, p99)
- [ ] Мониторинг размера memory footprint
- [ ] Профилирование: найти и устранить bottleneck'и
- [ ] Budget: время onload < 500ms, обработка текста < 2s

**Результат:** Молниеносный плагин, не замедляющий Obsidian.
